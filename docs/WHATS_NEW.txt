v1.0 — FIRST PUBLIC RELEASE

- Prva javna verzija programa pod konačnim nazivom SubtitleBoom.
- Zasnovana na razvojnoj liniji Subtitle Aligner v4.1.1.
- Program je dobio konačni naziv SubtitleBoom.
- Izvršni fajl sada se zove SubtitleBoom.exe.
- Interfejs, build poruke, dokumentacija i jezički paketi koriste novi naziv.
- Finalno javno izdanje koristi folder SubtitleBoom_Data za projektne podatke.
- Ispravljen CS0103 build problem iz v4.1.0.
- Dodat izbor između 15 jezika interfejsa.
- Automatski izbor prati jezik Windowsa, uz engleski fallback.
- Jezik interfejsa ne utiče na Whisper jezik obrade.
